# Ícones Faltantes para Biblioteca Desktop

> Base: 273 ícones atuais

## Como baixar do Icons8

```
URL: https://img.icons8.com/3d-fluency/50/<nome>.png   (tentar 3D primeiro)
URL: https://img.icons8.com/fluency/50/<nome>.png       (fallback 2D)
URL: https://img.icons8.com/3d-fluency/100/<nome>.png   (tentar 3D primeiro)
URL: https://img.icons8.com/fluency/100/<nome>.png       (fallback 2D)
```

> Regra: tentar **3d-fluency** primeiro; se 404, usar **fluency**.
> Salvar como:
> - `icons8-<nome>-3d-50.png` em `50x50/` (se 3d-fluency)
> - `icons8-<nome>-2d-50.png` em `50x50/` (se fluency)
> - mesmo padrão para `100x100/`
> Depois rodar `python processa-icones.py` na raiz para gerar os demais tamanhos e .ico.
